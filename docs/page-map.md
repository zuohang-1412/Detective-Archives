# 页面与交互规划 v0.1

## 1. 页面结构

```text
首页
├─ 搜索入口
├─ 本期精选
└─ 侦探档案详情
   ├─ 人物资料
   ├─ 代表作品
   └─ 作品详情

档案
├─ 搜索
├─ 国家/时代/分类/标签/主体类型组合筛选（API 与小程序均已实现）
├─ 每页 30 条，支持触底或按钮继续加载，直至展示全部人物
└─ 侦探档案详情

我的档案馆
├─ 想读/在读/已读
├─ 想看/在看/已看
├─ 我的短评与长评
└─ 账号设置

社区（P1）
├─ 最新动态（已实现）
├─ 作品讨论（已由评价详情承载）
├─ 话题（后续增强）
└─ 用户主页（后续增强）

AI 创作室（P2）
├─ 原创故事设定
├─ 剧本与分镜
├─ 视频生成任务
└─ 发布前审核
```

## 3. 运营后台页面

| 页面 | 核心任务 |
|---|---|
| 仪表盘 | 查看访问转化、留存、社区治理样本和链接健康度 |
| 侦探管理 | 新增、编辑、发布、下架人物档案 |
| 作品管理 | 创建/编辑书目与影视信息，维护多位创作者及多位侦探关联 |
| 正版链接管理 | 维护渠道、地区、有效期和状态 |
| 评论审核 | 处理待审、举报、申诉恢复和剧透标记 |
| 用户管理 | 查看用户、调整角色并限制普通账号 |
| 审计日志 | 追踪关键内容和权限变更 |

当前后台已实现核心产品指标仪表盘、评价/回复审核、剧透标记纠正、举报与申诉处理、普通用户限时处置、用户角色、审计日志，以及侦探、代表案件、来源、作品和正版链接的新建、编辑、审核发布、隐藏与启停。作品表单支持多创作者身份、多侦探搜索勾选及编辑回填，关联更新与作品字段处于同一事务。正版链接支持点击统计、读者失效反馈和后台结案停用；所有后台列表接口每页最多 50 条，页面会继续读取后续分页，避免固定上限截断运营数据。

用户侧已提供用户协议、隐私政策、微信平台隐私指引入口、运营主体/联系渠道展示、个人数据 JSON 导出和两次确认的账号注销入口。导出前会明确提示文件包含个人信息，下载完成后通过微信文件分享能力由用户主动保存或发送。登录页会查询微信侧待授权状态，只有平台授权与业务协议均满足后才建立业务身份；正式发布前仍必须把占位运营信息替换为真实信息，并完成公众平台声明、法务与真机复核。

## 4. 页面通用状态

每个数据页面均需要覆盖：

- 首次加载。
- 加载成功且有数据。
- 加载成功但无数据。
- 网络错误并允许重试。
- 登录失效并引导重新登录。
- 内容已下架或无权限。
- 写入中防止重复提交。
- 写入成功后局部刷新。
- 账号被限制后，页面不再请求书架和本人评价接口，只显示限制期限与原因提示；普通写入返回 403，但当前会话仍可用于导出个人数据、退出和注销。
- 个人数据导出必须经二次提示，由用户主动分享临时 JSON 文件；客户端不得自动复制或上传文件内容。

## 5. 关键交互规则

- 评价默认不展示剧透内容，用户主动展开后才可见。
- 审核员可从待审队列或举报队列补标/取消评价与回复的剧透属性；操作不改变发布状态，重复提交不重复写审核和审计记录。
- 正版链接跳转前显示渠道名称，不使用“免费阅读”等无法持续保证的表述。
- 正版链接点击前由服务端再次确认启用状态；确认失败时停止复制或跳转并引导提交链接反馈，不回退使用页面缓存的旧地址。
- 阅读状态切换为幂等操作；快速重复点击只保留最终状态。
- 被审核隐藏的内容对作者保留状态说明，对其他用户不可见。
- 作者可从“我的评价”对已隐藏内容申请复核；开放申诉处理期间如编辑或删除原内容，申诉自动取消；管理员批准后内容恢复公开。
- 审核拒绝与发布后隐藏使用不同状态；作者可在“我的评价”看到“未通过”，修改后重新进入待审核。
- 删除用户内容优先软删除，以便处理申诉和审计。
- 作品评价与讨论回复提供“加载更多”，个人书架和我的评价以每页最多 50 条继续读取全部记录。
- 作品隐藏或归档后不再进入公开列表/详情；已有书架记录继续显示标题、状态、进度和不可用提示，用户可以移除但不能继续更新该作品状态。
- 作品关联编辑采用完整替换语义；保存前检查重复创作者身份与重复侦探，任一侦探不存在时作品字段及全部关联均不变。
- 社区动态只展示已发布评价、已发布作品和有效作者；筛选变化会重置分页，触底或按钮加载更多，失败时保留明确重试入口。
