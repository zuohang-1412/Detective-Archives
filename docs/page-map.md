# 页面与交互规划 v0.1

## 1. 页面结构

```text
首页
├─ 搜索入口
├─ 本期精选
└─ 侦探档案详情
   ├─ 人物资料
   ├─ 代表作品
   └─ 作品详情

档案
├─ 搜索
├─ 国家/年代/类型筛选（P0 待实现）
└─ 侦探档案详情

我的档案馆（P0 待实现）
├─ 想读/在读/已读
├─ 想看/在看/已看
├─ 我的短评与长评
└─ 账号设置

社区（P1）
├─ 最新动态
├─ 作品讨论
├─ 话题
└─ 用户主页

AI 创作室（P2）
├─ 原创故事设定
├─ 剧本与分镜
├─ 视频生成任务
└─ 发布前审核
```

## 2. P0 页面清单

| 页面 | 目标 | 核心内容 | 状态 |
|---|---|---|---|
| 首页 | 建立产品认知并引导发现 | 品牌说明、精选侦探、搜索入口 | 已实现基础版 |
| 档案列表 | 快速查找侦探 | 搜索、筛选、档案卡片 | 已实现搜索；筛选待实现 |
| 侦探详情 | 从人物发现作品 | 人物简介、标签、代表作品 | 已实现基础版 |
| 作品详情 | 了解作品并前往正版渠道 | 简介、类型、年份、关联侦探、官方链接 | 已实现基础版；评分、评论待实现 |
| 登录授权 | 建立用户身份 | 微信登录、协议确认 | 未实现 |
| 我的档案馆 | 管理阅读/观看进度 | 分类书架、最近更新 | 未实现 |
| 写短评 | 快速表达感受 | 评分、正文、剧透标记 | 未实现 |
| 写长评 | 发布读后感/观后感 | 标题、正文、关联作品 | 未实现 |
| 评论详情 | 查看讨论上下文 | 原文、回复、点赞、举报 | 未实现 |
| 举报 | 提交违规线索 | 原因、补充说明 | 未实现 |

## 3. 运营后台页面

| 页面 | 核心任务 |
|---|---|
| 仪表盘 | 查看新增用户、评论、举报和链接健康度 |
| 侦探管理 | 新增、编辑、发布、下架人物档案 |
| 作品管理 | 维护书目、影视信息与人物关联 |
| 正版链接管理 | 维护渠道、地区、有效期和状态 |
| 评论审核 | 处理待审、举报和剧透标记 |
| 用户管理 | 查看违规记录并限制账号 |
| 审计日志 | 追踪关键内容和权限变更 |

## 4. 页面通用状态

每个数据页面均需要覆盖：

- 首次加载。
- 加载成功且有数据。
- 加载成功但无数据。
- 网络错误并允许重试。
- 登录失效并引导重新登录。
- 内容已下架或无权限。
- 写入中防止重复提交。
- 写入成功后局部刷新。

## 5. 关键交互规则

- 评价默认不展示剧透内容，用户主动展开后才可见。
- 正版链接跳转前显示渠道名称，不使用“免费阅读”等无法持续保证的表述。
- 阅读状态切换为幂等操作；快速重复点击只保留最终状态。
- 被审核隐藏的内容对作者保留状态说明，对其他用户不可见。
- 删除用户内容优先软删除，以便处理申诉和审计。
