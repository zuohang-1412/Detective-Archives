# 侦探档案馆上线检查表

## P0：不通过不得上线

- [ ] `npm ci` 和 `npm run check` 全部通过。
- [ ] 真实生产环境执行 `npm run release:check` 通过。
- [ ] 所有数据库迁移成功，`npm run check:db` 与 `npm run check:db-api` 通过。
- [ ] 微信小程序 AppID、合法域名、服务类目、隐私保护指引和用户协议已配置。
- [ ] API 域名 HTTPS 证书有效，HTTP 自动跳转 HTTPS，数据库未暴露公网。
- [ ] 微信真机完成登录、书架、评论、举报、注销全链路验证。
- [ ] 后台完成登录、审核、举报、用户处置和作品链接维护验证。
- [ ] 未登录用户不能写入；普通用户不能访问后台；待审核内容不会公开。
- [ ] 生产日志不包含 AppSecret、密码、微信 code 或完整 Bearer token。
- [ ] 已生成上线前数据库备份，且在隔离环境完成恢复验证。
- [ ] 已保存上一稳定镜像标签并验证回滚命令。

## P1：首发前完成

- [ ] `/ready` 外部探测与 `/metrics` 采集已接入，告警接收人明确。
- [ ] CORS 无通配符，登录和社区写接口限流生效。
- [ ] 后台管理员使用独立随机强密码，监控使用独立令牌。
- [ ] `npm run links:check` 已执行，失败项逐条人工复核，无盗版、非 HTTPS 或私网地址。
- [ ] 125 位目录人物、109 条图鉴索引、112 部正式作品、113 条有效正版链接及第 1～102 卷关联关系抽样复核。
- [ ] 小程序空态、断网、接口超时、无权限和内容已删除场景可理解。
- [ ] 运营人员已掌握审核、举报、用户处置和紧急下架流程。

## P2：发布后一周内观察

- [ ] 每日检查错误率、P95 延迟、登录成功率、审核积压和备份状态。
- [ ] 收集首批用户反馈，建立缺陷优先级和修复时限。
- [ ] 根据真实访问量调整连接池和限流阈值。
- [ ] 对高频搜索无结果项补充别名和作品资料。
